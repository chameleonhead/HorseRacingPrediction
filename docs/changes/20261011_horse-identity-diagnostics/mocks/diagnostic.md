# 読み取り専用診断モック

設計のみ。1280px / 390px。Settingsの低頻度操作から独立Pageへ移動し、固有URLへ再訪できる。全データ移行の画面ではない。

```text
その他設定 / 馬IDの診断
馬IDの診断
保存済みの情報を確認します。データの更新は行いません。

馬のID [ horse-…                         ]
       馬の詳細画面に表示されるIDを指定してください。
[診断]

ナムラアラバイ                            読取時刻 …
登録時の名前 …   正規化された名前 …   登録イベントの確認状態 …
保存済みJRA識別情報
  公開プロフィール …（有効/欠落/不正）
  収集リソース sourceIdentity … / sourceUrlから得た識別子 …
  矛盾の有無 … / 確認できなかった範囲 …

ID生成ルール              算出したID              現在IDとの比較
登録当時の入力による算出  horse-…                 一致/不一致/算出不可
現行の名前ベース          horse-…                 …
保存済みsourceベース      horse-…                 …

この結果は同一個体の証明や移行可能な計画ではありません。
保存先ごとの読取時点は異なります。未確認の履歴・参照があります。
[再取得]
```

loading: 前回結果を保持し「再取得中」、二重送信を防止。入力不正はfield近く。対象なしは「指定した馬が見つかりません」。欠落・未知JSONは「根拠を確認できません」と対象項目を残す。通信失敗は入力/前回時刻を保持し再取得。内部例外や生JSONは表示しない。

狭幅は入力・登録情報を縦積み、比較表はruleと結果を保持しIDを折り返す。button/input/linkはkeyboard操作可、labelとheadingを設定し状態を色だけで示さない。実行/再開/リセットbuttonなし。ブラウザーとAPI再起動後は古い結果を永続結果と扱わず、再訪して再取得する。
