# レース詳細の再取得操作

## 1280px・通常

```text
← レース一覧に戻る
メイクデビュー中山                 [編集] [JRAから再取得]
2026/09/06 中山 6R

コース …  天候・馬場 …  状態 …
概要 / 出走表 / 結果 / …

取得状況
再取得    完了  2026/09/08 14:30   [処理の詳細]
天候 …  馬場 …  払戻 …
```

## 確認ダイアログ

```text
JRAからレース情報を再取得
2026/09/06 中山6R メイクデビュー中山

このレースの基本情報・出走情報・公開済みの結果と払戻を再取得します。
取得した項目はJRAの情報で更新します。

                 [キャンセル] [再取得を依頼]
```

取得範囲の文章は利用者の選択で確定する。

## 360px・依頼受付後

```text
← レース一覧に戻る
メイクデビュー中山
2026/09/06 中山 6R
[編集] [再取得を依頼済み（無効）]

再取得を受け付けました。
取得状況: 受付済み
[処理の詳細]
（既存のレース情報）
```

取得中は状態文言を更新。完了時は新しいレース情報を表示する。送信失敗・収集失敗は理由と再依頼操作を表示する。読み込み中・未検出では再取得操作を有効にしない。ダイアログは画面内に収まり、閉じた後は起動ボタンへフォーカスを戻す。
