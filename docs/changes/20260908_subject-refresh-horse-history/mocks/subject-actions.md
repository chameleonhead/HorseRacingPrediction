# 馬・調教師詳細の収集操作

## 1280px・馬詳細

```text
← 馬一覧
対象の馬                       [編集] [JRAから再取得]
プロフィール …

出走履歴                           [過去レースを取得]
過去レース取得: 取得中  完了8 / 発見12 / 失敗1 / 対象外2
[処理の詳細]
日付・開催・R・レース名 … → レース詳細
```

## 調教師詳細

```text

再取得: 完了  最終取得日時 …        [処理の詳細]

```

## 360px・確認

```text
この馬の過去レースを取得
対象の馬

JRAで公開されている出走履歴を辿り、
各レースの全出走馬・結果・払戻を取得します。
保存済みのレースも、変更点を更新します。

[キャンセル] [取得を依頼]
```

狭い画面では操作と進捗を折り返す。未取得は空表示と取得操作、送信/収集失敗は理由と再試行導線、実行中は重複操作不可とする。
