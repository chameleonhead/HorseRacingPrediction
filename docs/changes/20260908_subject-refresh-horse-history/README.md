# 馬・調教師の再取得と馬を起点とする過去レース収集

- Status: Approved
- Created: 2026-09-08
- Updated: 2026-09-08

## Context

利用者から「馬や調教師の情報も更新できるように」「特に馬を起点にして過去のレース情報を取得する経路」と追加要望を受けた。
[レース詳細からの再取得](../20260908_race-detail-reacquisition/README.md)を基盤に拡張する。
現在の馬・調教師詳細には編集のみがあり、収集依頼操作はない。旧HorseHistory/TrainerProfileの要求モデル・計画処理は残っているが、対応Worker登録が無効で、現在のJraNavigatorにも馬・調教師の詳細遷移がない。

## Goals

- 馬詳細からプロフィールを再取得し、判明した変更をすべて更新する。
- 調教師詳細からプロフィールを再取得し、判明した変更をすべて更新する。
- 馬詳細から、その馬のJRA公開出走履歴を辿り、過去レース全体を新規取得または更新する。

## Scope

- プロフィールはJRAが対象ページで公開し、対象を同定できた情報を取得する。馬名・性別・生年月日・毛色・血統・生産者・産地・馬主・調教師、調教師の氏名・所属・生年月日・免許情報などについて、公開・取得できた項目の変更を反映する。非公開項目を推測しない。
- 馬の過去レースは、JRAの馬詳細の出走履歴に掲載され、JRA結果ページへ辿れる全レースを対象とする。初期仕様で直近N件や特定年以降に切り詰めない。ページ送りがあれば最終ページまで探索する。
- 対象レースはその馬1頭の成績に限定せず、レース基本情報・全出走馬・結果・払戻を収集する。保存済みでも変更点を更新する。
- 地方・海外等、JRAの結果ページがない履歴は対象外理由を表示し、JRAレースへ誤変換しない。レースから他馬の全履歴へ再帰的に探索はしない。
- 取得できない値で既存値を消さない。利用者メモ・予想・購入情報は維持する。プロフィールの現在情報で過去レース時点の馬主・調教師を上書きしない。

## Experience and interaction design

- 馬詳細ヘッダーに「JRAから再取得」、出走履歴の見出し付近に「過去レースを取得」を配置する。
- 調教師詳細ヘッダーに「JRAから再取得」を配置する。
- 各操作の確認画面で対象と更新範囲を表示し、取得できた変更点がすべて更新されることを明示する。
- 受付後も詳細画面に留まり、受付済み・取得中・完了・失敗とジョブリンクを表示する。プロフィール完了時は詳細を、過去レース取得完了時は出走履歴を再読込する。
- 過去レース取得は発見件数・完了件数・失敗件数・対象外件数を表示する。一部成功を全件成功として扱わず、失敗分から再試行できる。
- 同一対象・同一操作の待機/実行中依頼はサーバーで重複抑止する。ページ再訪・別タブでも状態を確認する。
- 同名対象を一意に同定できない場合は更新せず、確認が必要な理由を表示する。名前だけで別個体・別人を更新しない。
- 360pxで主要操作を維持し、キーボード・フォーカス・処理状態の読み上げを確認する。

## Technical impact

- Apiに対象IDベースの再取得・履歴収集要求と状態照会を追加。既存認証・監査・永続ジョブ・キュー配送を利用する。
- JRAの公開識別子、既知の引用元、登録名・生年月日等を用いて同一性を確認し、既存オブジェクトIDを維持する。公開識別子と引用元を再利用可能な形で保存する。
- 現行JraSession/JraNavigator/PageParser層に馬検索・馬詳細・出走履歴ページ送り・調教師検索/詳細を追加。URL推測生成をせずブラウザー上のリンク・フォームで辿る。
- 稼働中Collectorの常駐・単発経路にプロフィール再取得と履歴探索ジョブを追加する。無効化済みの旧Workerへ依存させない。
- 馬起点の履歴探索を親ジョブ、発見したレースの取得を子ジョブとする。対象レースは日付・競馬場・R・公開識別子で照合し、既存レースに紐付ける。未登録は新規作成し、登録済みは再取得更新する。
- レース単位でチェックポイントと失敗を残し、中断後に成功済み部分をやり直さず再開できる。ユーザーによる新たな再取得では保存済みレースも更新対象とする。
- ドメイン・read model・API DTOの不足項目は追加し、既存イベント互換とデータを維持するマイグレーションを行う。

## Acceptance criteria

1. 馬・調教師の詳細から再取得を依頼でき、変更したプロフィールが完了後に反映される。
2. 馬詳細の「過去レースを取得」からJRA出走履歴を辿り、未登録レースが追加される。
3. 保存済みレースも差分を更新し、全出走馬・結果・払戻がレース詳細から確認できる。
4. ページ送りを含む全掲載履歴が対象になり、同一レースを重複登録しない。
5. 同定不能・対象外・未公開・部分失敗を区別し、別対象の更新・既存値の不当な消去がない。
6. 同時依頼の重複抑止、中断再開、失敗分再試行、常駐/単発実行が検証される。
7. 360pxでの主要操作、キーボード、loading/empty/error/success状態を確認する。
