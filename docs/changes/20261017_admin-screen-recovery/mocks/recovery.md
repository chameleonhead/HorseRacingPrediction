診断セクションは候補なしでも使用可能。確認前に実行操作を表示しても無効理由を明示し、Primary Actionは現在の一段階に絞る。GUID/長いsource番号は完全表示し折返す。390pxでは各行を縦積み、主要操作・根拠・エラー・時刻は隠さない。Keyboardで候補/checkbox/preview/確認/状態更新をたどれる。再読込で未保存の候補が消える場合は離脱確認を出し、保存済みはrequestKey/operationIdから復帰する。

Loadingは「未取得」であり0件/正常を表さない。通信エラーは入力と旧結果を保持。受付確認待ちで自動再送せず、明示的な同GUID再送のみ現在状態を検査する。追加TokenやGitHub設定は不要で、通常の管理画面の認証を使用する。Tokenの入力・表示欄、任意SQL、DBパス、shell、resetは置かない。通常API終了から検証完了まで同一コンテナの制御プロセスが担当し、画面の再接続は実行や収集再開を引き起こさない。Partial/Interruptedは停止し、成功済み移行の確認再実行は読み取り専用に限る。
