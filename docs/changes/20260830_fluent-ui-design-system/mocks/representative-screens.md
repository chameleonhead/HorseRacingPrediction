- 左 rail と main surface の色差は小さくし、active item は accent の細い indicator と neutral fill で示す。

- 一覧 row 全体を詳細への target にし、状態はアイコン、日本語、色を併用する。
- 各 row はレースオブジェクトの縮約表現であり、`主ラベル → 状態 → 主要属性 → 関係 → 詳細` の順序を保つ。

│                  │ 2  3  △△△△       騎手 △△      1 1/2                     │

- 大きな card の入れ子を避け、section heading と divider で一つの読み順を作る。
- 低頻度の編集や技術操作は overflow menu / disclosure へ移す。
- entity 名は一貫した link affordance を持つ。
- レースを canonical object として表示し、出走馬、騎手、予想票、関連ジョブを関係リンクとして辿れるようにする。

## Object item anatomy

```text
┌──────────────────────────────────────────────────────────────┐
│ [種類] 主ラベル                                      [状態] │  Identity / state
│ 主要属性 A ・ 主要属性 B                                    │  Attributes
│ 関係ラベル: [関連オブジェクト]                              │  Relationship
│                                                        [›]  │  Canonical detail
└──────────────────────────────────────────────────────────────┘
```

- 種類アイコンと主ラベルは、同じ種類のどの一覧でも同じ規則を使う。
- status はオブジェクトの現在状態であり、装飾 badge として無意味に増やさない。
- 関係はラベルを伴うリンクとし、文字列しか取得できない場合も関係の種類を示す。
- 編集、再投入など高リスク CTA は item 内に並べず、canonical detail で対象と影響を確認してから実行する。

## Shared states

```text
Loading                         Empty
┌──────────────────────────┐    ┌──────────────────────────┐
│  ◌ レースを読み込み中…  │    │  該当するレースなし      │
│                          │    │  条件を変更してください  │
└──────────────────────────┘    │  [条件をクリア]          │
                                └──────────────────────────┘

Recoverable error               Dangerous confirmation
┌──────────────────────────┐    ┌──────────────────────────┐
│ 読み込めませんでした    │    │ ジョブを再投入しますか？ │
│ 通信を確認してください  │    │ 対象: 8/30 新潟11R       │
│ [再試行] [技術情報 ›]   │    │ [キャンセル] [再投入]    │
└──────────────────────────┘    └──────────────────────────┘
```

- loading は layout shift を抑え、操作可能な既存内容を不必要に消さない。
- empty は成功した 0 件と error を区別する。
- dialog の初期 focus、Escape、focus return、busy 中の二重実行防止を component contract に含める。
