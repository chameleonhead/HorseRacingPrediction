# 競馬場名を含むJRAレース名の抽出修正

- Status: Implemented
- Created: 2026-09-08
- Updated: 2026-09-08

## Context

報告URL: https://www.jra.go.jp/JRADB/accessS.html?CNAME=pw01sde1006202604020620260906/96

JRA公式ページで2026年9月6日・中山6Rの見出しが「メイクデビュー中山」であることを確認した。
`RaceResultPageParser.ParseRaceName` は `RaceCourseNames.Parse(candidate)` が競馬場を返す見出しを除外する。しかし同メソッドは部分一致のため、「メイクデビュー中山」も除外され、その後の無関係な見出しを採用し得る。
`RaceCardPageParser.ParseRaceName` にも同じ問題がある。

## Goals

- 競馬場名を含む正式なレース名を欠落・置換せず取得する。
- 結果ページと出馬表で同じ不具合を防ぐ。

## Non-goals

- 保存済みデータの一括修復、UI変更、ブラウザー起動・リンク抽出処理の変更。
- 競馬場を本文から取得する既存の部分一致仕様の変更。

## Decisions

- レース名候補の除外では、競馬場名を含むことだけを理由に除外しない。競馬場名単独、開催情報、日付、サイト共通見出しを区別する。
- 結果ページの日付・レース番号を含む見出しを起点とする方式を維持する。
- レース名の走査が払戻金・勝馬の紹介等の後続セクションへ進んだ場合、馬名等をレース名として採用しない。取得不能時は既存の例外方針を維持する。
- 出馬表は既存の取得不能時の契約を維持する。

## Technical impact

対象は結果・出馬表パーサー、必要に応じた共通の見出し判定、および関連パーサーテスト。既存の `PlaywrightWebBrowser.cs` の未コミット変更は本変更に含めない。

## Acceptance criteria

1. 報告ページの見出し順序を反映した固定スナップショットから「メイクデビュー中山」を取得する。
2. 「メイクデビュー阪神」「東京優駿」など競馬場名を含むレース名を、結果・出馬表の両方で取得する。
3. 競馬場名単独・開催情報・サイト共通見出しをレース名にしない。
4. 結果ページで正式なレース名が欠けても、勝馬の紹介内の馬名を代用せず例外にする。
5. 既存の通常レース名・障害レース・グレード付き名称のテストが成功する。

- `docs/24-jra-html-change-diagnostics.md`、`docs/22-collector-design.md` を確認した。診断形式、収集フロー、APIの変更はなく更新不要。
