## レースから収集状態を辿る

```text
関連する収集
2026年8月28日の収集                 › 収集対象日
24 / 24 レース完了

出馬表の収集                         › ジョブ
完了・09:42 更新

レース結果の収集                     › ジョブ
デッドレター・3回失敗・10:36 更新
```

## 移動時の規則

- リンク文言は遷移先のオブジェクト名を使う
- 補助ラベルで関係を明示する（対象レース、騎手、親ジョブなど）
- 遷移先でも起点との関係が理解できる文脈を表示する
- 現在の関係と過去のレース時点の関係を混同しない
- ID で関係を保証できない対象は、名前だけをリンクにしない
