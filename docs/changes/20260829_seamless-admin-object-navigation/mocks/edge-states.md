# 状態別・レスポンシブ補助モック

正常系モックを補完するための状態モック。最終的な色や寸法ではなく、情報の優先順位と操作契約を確認する。

## 補正保存失敗・モバイル 320 CSS px

```text
← 馬詳細

データを補正する
対象: ○○○○

! 訂正を保存できませんでした
  変更は保存されていません。
  入力内容を確認して、もう一度試してください。

馬名 [○○○○________________]
理由 [任意__________________]

[もう一度保存する]  [キャンセル]
```

フォーム上部の `role="alert"` に表示し、入力値を保持する。検索エラー用の再試行とは異なり、操作名と変更結果を明示する。

## 再投入結果不明・モバイル 320 CSS px

```text
確認

再投入の結果を確認できませんでした
対象: JRA・2026年8月28日・札幌 9R

処理が完了したか判定できないため、再投入は行いません。
元のジョブ詳細へ戻り、最新状態を確認してください。

[ジョブ詳細へ戻る]
```

フォーム送信中はこの画面へ遷移しない。想定外 API エラー確定後にだけ表示し、再試行ボタンは置かない。

## 権限不足・デスクトップ 1024 CSS px

```text
データを補正する

! この操作を実行する権限がありません
  対象は表示できますが、訂正・名寄せ・再投入は許可されていません。

[詳細へ戻る]
```

権限不足を入力エラーとして表示せず、編集項目や送信ボタンを表示しない。読み取り導線は維持する。

## 部分取得・デスクトップ 1024 CSS px

```text
レース結果

一部の情報を取得できませんでした
  出走馬: 14頭中14頭 取得済み
  着順: 14件中10件 取得済み
  払戻: 未取得

[ジョブを確認する]  [再読み込み]

取得済みの出走馬と着順は表示し、未取得・該当なし・値なしを区別する。
```

```text
馬

検索中...
直前の検索結果を保持
（結果領域上部に読み込み状態を表示）

--- 検索完了後 ---
1,248 頭
イクイノックス              ›
牡6・2019年3月23日生
```

検索完了後に一覧を差し替え、空状態・エラー状態では結果領域を更新する。
