## Narrow 390px

```text
バックグラウンド処理の稼働状況
このAPIインスタンスの記録
更新 10/08 10:30:00 JST

ジョブ配送       待機・実行枠満杯
最終正常確認  10/08 10:29:59 JST
最終進行      10/08 10:28:10 JST
▸ 詳細

新規レース探索   待機・対象なし
最終正常確認  10/08 10:29:30 JST
最終進行      10/08 09:00:01 JST
▸ 詳細
```

状態の確認だけで操作を要求しない。初期読込はこのセクションのUiState、再起動直後は「起動後まだ未確認」、無効設定は「設定で無効」。取得失敗時は前回値と「更新できません・表示は以前の情報です」を残し、ヘッダーの更新で再試行する。API応答を取得できない状態と、取得した結果が停止を示す状態を混同しない。時刻表示はJSTを明示し、APIのUTC値を既存JstTimeで整形する。

最終正常確認は空周期でも進む。最終進行は実際の作成・回収・送信等があった場合のみ進む。色だけで意味を伝えず、読み上げ・キーボード操作を保つ。横幅のために状態や重要な時刻を隠さない。具体的な折返しとFluentDataGridの表現は実装時のブラウザー検証で確定する。
