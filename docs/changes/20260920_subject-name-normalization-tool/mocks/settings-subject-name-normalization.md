## States

- 検索前: 「対象種別と名称またはIDを入力してください」
- Loading: 既存結果を保持し、検索操作を無効化して進行表示
- 0件: 「一致する登録済み対象はありません」
- 候補なし: 結果は表示し、「正規化が必要な対象はありません」
- Error: 入力を保持し、再検索を案内
- Partial result: 成功、状態変化によるskip、失敗を件数と対象別理由で表示して再検索
