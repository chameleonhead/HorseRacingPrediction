# 要対応データ補正ジョブ ワイヤーフレーム

## Desktop（1440px、候補あり）

```text
運用 / その他設定                                      [再読込]
その他設定

要対応データ補正
収集ジョブとは別の、確認後に実行する補正です。

[すべて 8] [競走馬 3] [騎手 2] [調教師 2] [馬主 1]
実行可能 6件  要確認 2件                 [実行可能をすべて選択]

選択  主体    状態      統合元 → 統合先        根拠            影響・判定
[x]   競走馬  実行可能  馬名 / ID → 馬名 / ID  JRA識別子・Race  task 1件停止
[ ]   騎手    要確認    氏名 / ID → 氏名 / ID  同一RaceEntry    異なる候補あり
[x]   馬主    実行可能  名称 / ID → 名称 / ID  同一RaceEntry    alias 2件移管

6件を選択                              [選択した補正を確認]
```

確認Dialogは主体別件数、source→target、redirect/alias、収集停止、履歴保持、取消不可を表示する。

## Narrow（390px、候補あり）

```text
その他設定                                   [再読込]
[すべて] [競走馬] [騎手] [調教師] [馬主]

[x] 競走馬  実行可能
統合元  馬名 / ID
統合先  馬名 / ID
根拠    JRA識別子 / Race
影響    収集task 1件停止
判定    適用可能
-----------------------------------------------
[ ] 騎手  要確認（disabled）
...

1件を選択
[選択した補正を確認]
```

IDとJRA識別子は折り返し、横overflowを発生させない。状態は色だけでなく文言で示す。
