# 期間レース再取得 — テキストワイヤーフレーム

対象: `/jobs`、desktop と 320px 狭幅、通常/validation/通信失敗/受付済み状態。

```text
収集ジョブ                                      [収集を依頼]

  ダイアログ: 収集を依頼
  ┌──────────────────────────────────────────────┐
  │ 種類                                         │
  │  [期間を指定してレースを再取得]              │
  │                                              │
  │ 対象: JRA                                    │
  │ [先週末を入力]                               │
  │                                              │
  │ 開始日 *              終了日 *               │
  │ [2026-09-12]          [2026-09-13]            │
  │ JST・両端を含む                              │
  │                                              │
  │ [キャンセル]                    [内容を確認] │
  └──────────────────────────────────────────────┘

  確認
  ┌──────────────────────────────────────────────┐
  │ 2026-09-12〜2026-09-13（2日）                │
  │ ・JRA公式から各日のレースを探し直す          │
  │ ・登録済みレースも最新の出馬表/結果へ更新    │
  │ ・過去オッズ時系列は対象外                    │
  │                                              │
  │ [入力に戻る]                  [再取得を依頼] │
  └──────────────────────────────────────────────┘
```

狭幅では開始日、終了日、操作を1列に積む。validation error は各日付直下と要約へ表示し、通信失敗でも値を保持する。送信中は全送信操作を無効化し、処理中を読み上げ可能にする。受付後は batch ID を主情報にせず、期間、日数、新規/集約 task 数、進捗導線を表示する。
