
## Narrow viewport

候補を一列の縦積みにする。radio、名前、JRA識別子、根拠、外部リンクを同じ候補group内に保持し、
Primary Actionは候補列の末尾に全幅で配置する。技術的な元Resource IDは折返し可能な詳細表示へ置き、
候補判断に必要な名前とJRAリンクを非表示にしない。

生成元は候補より先に一列表示し、対象名と「生成元ジョブを開く」を優先する。長いIDは折り返し、
対象名やリンクを画面幅だけで非表示にしない。

## States

- Loading: 候補領域内に「候補を読み込んでいます」。ページ全体は保持する。
- Empty/legacy: 「この試行には候補情報が保存されていません」。利用可能な場合だけ再探索、または
  旧血統参照として終了する操作を表示する。
- Missing origin: 保存済みの生成元種類・provider・IDを表示し、「生成元の詳細を取得できません」を
  併記する。候補確認と他のJob Detail機能は継続する。
- Validation: 未選択ではPrimary Actionを無効化し、候補groupの近くに選択要求を示す。
- Submitting: Primary Actionを無効化し、二重送信を防ぐ。
- Error: 選択状態を保持し、「復旧を依頼できませんでした」と再試行導線を表示する。
- Concurrent resolution: 既に解決済みなら成功済みの選択先リンクを表示し、新しいtaskを増やさない。
