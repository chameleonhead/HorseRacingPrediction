# 障害のまとまり — レスポンシブ・ワイヤーフレーム

## Desktop（幅 1280px、要対応・障害あり）

```text
障害のまとまり                         同じ原因をまとめて確認できます

原因                         ジョブ種類       件数    最新発生          最新の内容                    操作
UnexpectedPage               レース詳細の収集   12件    09/14 14:20      想定したページを確認できません… 詳細を見る ›
SubjectNotIdentified          競走馬情報の収集    5件    09/14 13:05      対象の競走馬を特定できません…   詳細を見る ›
原因未分類                    オッズの収集        2件    09/13 16:40      実行履歴を確認してください       詳細を見る ›

                                             すべての障害（9原因）を見る ›
```

- 一覧は1列とし、同じ項目を縦に揃えて原因と件数を走査できるようにする。
- 原因を主情報、ジョブ種類、件数、最新発生を判断情報、最新メッセージを補足情報とする。
- 行全体を詳細リンクにしつつ、右端に「詳細を見る」を表示して遷移可能であることを明示する。
- 長い最新メッセージは1行で省略し、完全な内容と対象は詳細ページで確認する。

## Mobile（幅 390px、要対応・障害あり）

```text
障害のまとまり
同じ原因をまとめて確認できます

┌──────────────────────────────┐
│ UnexpectedPage          12件 │
│ レース詳細の収集              │
│ 最新発生 09/14 14:20          │
│ 想定したページを確認できませ   │
│ ん。ページ構造を確認して…       │
│                       詳細を見る › │
└──────────────────────────────┘

┌──────────────────────────────┐
│ SubjectNotIdentified      5件 │
│ 競走馬情報の収集                │
│ 最新発生 09/14 13:05            │
│ 対象の競走馬を特定できません…   │
│                       詳細を見る › │
└──────────────────────────────┘

すべての障害（9原因）を見る ›
```

- 原因と件数を先頭行に置き、件数は右寄せする。
- ジョブ種類と最新発生を独立行にし、長い最新メッセージは最大3行まで表示する。
- 横スクロールを発生させず、英数字の長いエラーコードや空白のない文でも折り返せる。
- タップ領域はカード全体とし、「詳細を見る」を残して操作の意味を明示する。

## States

- Loading: 既存のページLoading表示を維持する。
- Empty: 障害がない場合は障害セクション自体を表示しない現行動作を維持する。
- Error: API接続エラーは既存のページError表示を維持する。
- Large/long values: 長いエラーコード、長い日本語・英語メッセージ、2桁以上の件数で折返し・省略・整列を確認する。
