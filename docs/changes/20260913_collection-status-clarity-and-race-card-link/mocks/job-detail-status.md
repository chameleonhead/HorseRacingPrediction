# Job detail status wireframe

## Active Task after successful collection

```text
レース結果の収集                         [実行待ち]

現在の処理          保存データ             障害対応
再取得を待機中      取得済み               未解決なし
開始可能 16:52      最終取得 16:47

┌ 情報 ──────────────────────────────┐
│ 再取得を待っています。                         │
│ 前回取得済みのデータは引き続き利用できます。   │
└───────────────────────────────────┘

[概要] [依頼履歴] [タスク履歴] [試行履歴] [障害履歴]
```

解決済みの障害は上部に赤く表示しない。

## Open failure

```text
出馬表の収集                             [要対応]

現在の処理          保存データ             障害対応
停止                未取得                 要対応 1件

┌ 要対応 ────────────────────────────┐
│ 想定と異なるページを取得しました。             │
│ 要求: RaceCard / 実際: RaceOdds                │
│ [再取得] [技術情報を表示]                       │
└───────────────────────────────────┘
```

## Narrow viewport

3つのSummaryを縦積みにし、現在処理パネル、Primary Action、タブの順を保つ。状態名を常に文字で表示し、色だけに依存しない。
