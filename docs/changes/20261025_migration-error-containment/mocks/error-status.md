# 移行エラー表示案（PC / 390px）

同じ詳細ページ階層を両幅で使用。以下は表示例であり本番原因の断定ではない。

```text
馬IDの移行
移行を停止しました
管理画面は利用できます。安全確認のためデータ操作は停止しています。

停止した段階   書き換え前の検証
理由           保存データの検証を完了できませんでした
確認時刻       yyyy/MM/dd HH:mm:ss（日本時間）
移行結果       未確認（成功とは表示しない）

[状態を更新]

詳細を表示 ▾
  依頼番号     <長い番号は幅内で折り返す>
  理由コード   <許可された短いコード>
```

- Pending/Running: 失敗を推測せず、最後に確認できた段階・時刻を表示。再訪だけでは実行しない。
- Failed/Partial: 状態と理由を色だけに依存せず表示。再実行・解除ボタンを追加しない。
- 原因不明:「処理が中断しました。詳しい原因は記録されていません」と明示。
- 記録読取不能:「移行状態を確認できません。データ操作は停止しています」。成功/取消可否を推測しない。
- 依頼なし:「表示できる移行依頼はありません」。通常画面は安全な通常モードでのみ利用可能。
- `/`、`/races`、`/jobs` 等からアクセスした保護中の利用者も、認証後にこの案内へ到達できる。APIへの失敗レスポンスをHTML成功へ変えない。
- キーボード操作可能な見出し・更新・詳細、視認できるfocus。最小HTML画面は通常Blazor起動に依存しない。通常画面では既存Fluent UIを使う。
