[x] 状態     主体                         元の収集ジョブ       エラー / 再収集方法

[x] 要確認   調教師 相沢 郁 ...           trainer-profile      主体名なし / 再収集不可

## Confirmation dialog

```text
選択した4件を対応不要として閉じますか？

この操作で元の収集ジョブ、試行履歴、主体データは削除されません。
選択した古い失敗通知だけが一覧から消えます。
同じ対象で新しい失敗が発生した場合は、再び要対応として表示されます。

[キャンセル] [対応不要として閉じる]
```
