# 未承認モック: 移行準備の中止

既存詳細画面、desktopおよび390px。同じ情報順、狭幅は縦積み/長い番号は折返し。

```text
移行状態とエラー
状態 / 確認できた段階 / 記録更新時刻 / 操作番号
結果・安全な理由

[準備を中止]  [状態を更新]
  確認: 業務データを変更せず、元の依頼とbackupを残します。
        安全確認できなければ中止しません。収集は停止を維持します。
  [ ] 上記を確認しました
  [中止を要求] [戻る]

確認中 → [状態を更新]のみ / 同じ依頼の結果を再読込
拒否   → 安全な理由・時刻 / 保護画面を維持、データ操作なし
完了   → 元依頼:準備中止 / 収集:停止 / 通常画面へ
         [新しい移行依頼を作成] （入力引継ぎのみ、自動実行しない）
```

未知/Partial/Applying以後は中止操作を表示しない。表示時点は要求候補であり、安全な解除はcontrollerの実行時証明後だけ。keyboardで確認/要求/戻るを操作でき、pendingで送信を無効化。認証切れ/CSRF/通信失敗/再読込でも同じ保存結果へ戻る。取消中の例外は保護画面に留め、元の番号・理由・最終更新時刻を失わない。
