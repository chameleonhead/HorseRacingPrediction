# 管理 UI 実装監査

監査日: 2026-08-29

`admin-ui-design.md` の受け入れ基準を、API 管理画面、Collector 管理画面、公開 API、ReadModel、永続化処理と再照合した結果を記録する。

## 実装済み

| 領域 | 実装結果 |
|---|---|
| 共通 | 720 px 以下のドロワーナビ、44 px 操作領域、明示的なフォーカスリング、共通の読み込み・空状態、アプリ単位のエラー境界を追加 |
| レース | モバイル用オブジェクト一覧、出走と結果の統合、天候・馬場・払戻の取得状態、予想票導線、人馬・馬主へのリンク、訂正確認を追加 |
| 馬・騎手・調教師 | モバイル用一覧、共通参加履歴 API、起点に応じた履歴順序、関係サマリー、相互リンク、訂正確認を追加 |
| 馬主 | 派生 Owner オブジェクトの一覧・詳細、所有馬と参加履歴、別名統合、認証済み名寄せ API、操作者・理由・時刻を持つ監査履歴を追加 |
| 予想 | モバイル用一覧・印一覧、レースとの双方向導線、訂正・取り下げ確認を追加 |
| ジョブ | モバイル縦型一覧、正規詳細、確認付きリラン、楽観的競合検出、操作監査、生成関係・集約依存関係の双方向導線を追加 |
| 収集 | 日次・取得状態をモバイル用オブジェクト一覧へ変更し、直接再投入を監査付きジョブ詳細へ集約 |
| 開発ツール | リンク・フォーム・画像を折り返し可能なレコード表示へ変更。列数が任意の抽出表だけをキーボード操作可能な局所スクロール領域に限定 |

## バックエンド実装

| 要件 | 状況 | 実装 |
|---|---|---|
| ジョブ検索・詳細 API | 対応済み | canonical は `/api/admin/jobs` と `/api/admin/jobs/{jobId}`。旧 `/collection-tasks` UI は `/jobs` へリダイレクト |
| `jobId` ベース再投入・競合検出 | 対応済み | `ExpectedUpdatedAt` 不一致を 409 として処理 |
| 再投入監査 | 対応済み | 操作者、理由、旧状態、新状態、時刻を `job_operation_audits` に保存 |
| 親子ジョブ | 対応済み | `parent_job_id` を既存 SQLite に安全に追加し、月→日→収集へ伝播 |
| 共通参加履歴 | 対応済み | Horse / Jockey / Trainer を共通 DTO と API で提供 |
| Owner 名寄せ | 対応済み | 別名マッピングと統合監査の EF Core migration、API、UI、テストを追加 |
| レース時点の馬主参照 | 対応済み | 名寄せ後の OwnerId を出走 DTO で解決 |
| UI 参照エラー | 対応済み | ErrorBoundary で通信・描画例外を再読み込み可能な状態として表示 |

## 意図的に残すもの

- PageSnapshot の任意列テーブルは、列とセルの対応を保つ必要があるためカード化しない。ページ全体ではなく、ラベル付きの表領域だけを横スクロール可能にしている。
- .NET 10 LTS 移行、QuickGrid / Fluent UI Blazor の採否は UI 修正とは独立した基盤更新であり、本改修へ混在させない。
- 1280 px の list-detail 同時表示、収集対象日専用詳細、運用サマリーは将来の情報量増加時に導入する拡張であり、現在の一覧→詳細ユースケースを阻害しない。

## 検証

- ソリューションビルドと全自動テストを実施する。
- 静的監査で通常管理画面の横長テーブルが残っていないことを確認する。任意列を扱う PageSnapshot の表のみ例外とする。
- 320 / 360 / 736 / 1024 px、200% 拡大、実データを使ったブラウザー確認はリリース前の手動受け入れ項目とする。Collector 単独起動は管理 API への接続が必須である。
